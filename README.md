# Airline Review Intelligence

A project for organizing airline review data and turning it into useful insights. Project goals, scope, and architecture will be documented in [`docs/PROJECT_BLUEPRINT.md`](docs/PROJECT_BLUEPRINT.md).

## Repository structure

- `docs/` — project blueprint and AI-assisted development guidance.
- `PROJECT_STATE/` — current project status and decision records.
- `frontend/` — user interface.
- `backend/` — application services and APIs.
- `automation/` — scheduled or workflow automation.
- `collectors/` — data collection components.
- `database/` — schema and database-related assets.
- `data/` — data assets; do not commit secrets or sensitive personal information.
- `scripts/` — development and maintenance utilities.

Most component directories are initial placeholders. See the documents in `docs/` for the project guidance templates.
