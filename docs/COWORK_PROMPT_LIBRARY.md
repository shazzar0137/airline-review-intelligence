# Cowork Prompt Library

Reusable prompt templates for work on Airline Review Intelligence. Replace bracketed text before use and consult `PROJECT_BLUEPRINT.md` for project context.

## Plan a feature

> Using the project blueprint, propose an implementation plan for [feature]. Include affected components, data/privacy considerations, acceptance criteria, tests, and open questions. Do not make code changes yet.

## Implement a feature

> Implement [feature] in the appropriate component. Follow the project instructions and existing conventions. Add or update tests and documentation, run relevant checks, and summarize the changes and results.

## Review a change

> Review the changes for [feature or pull request]. Prioritize correctness, security, privacy, maintainability, and test coverage. Report actionable findings with file and line references; do not make changes.

## Investigate a bug

> Investigate [observed behavior]. Trace the relevant code, identify a likely root cause, and propose a minimal fix with regression tests. Distinguish confirmed facts from assumptions.

## Update project documentation

> Update documentation for [component or workflow] to match the current implementation. Verify details against the code and identify any unresolved questions instead of guessing.
